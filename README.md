# Fisica - Resumen y ejercicios

Repositorio personal para repasar el libro de fisica siguiendo un metodo de estudio practico y conciso.

## Metodo de estudio

Cada apartado se trabajara con esta estructura:

1. **Resumen conciso y claro**: explicar las ideas importantes sin reproducir innecesariamente el texto del libro.
2. **Ejemplo del libro paso a paso**: explicar datos, objetivo, principio fisico, ecuaciones, sustitucion, resultado e interpretacion.
3. **3 o 4 ejercicios del final**: seleccionar ejercicios representativos y resolverlos paso a paso.
4. **Dato curioso**: agregar una aplicacion, hecho historico, fenomeno cotidiano o consecuencia poco intuitiva relacionada con el apartado.

## Filosofia

El objetivo no es convertir el libro completo a Markdown, sino construir **apuntes propios para entender y repasar fisica rapidamente**.

La teoria debe ser breve pero suficiente. La parte practica se concentra en el ejemplo del libro y en 3 o 4 ejercicios seleccionados.

El dato curioso funciona como ancla de memoria y conecta la teoria con situaciones reales.
