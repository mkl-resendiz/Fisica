# Ejercicios del capítulo 2

El libro contiene 44 problemas, además de actividades, problemas adicionales y problemas de desafío.

En las notas del capítulo se seleccionaron ejercicios representativos para practicar:

- posición, desplazamiento y rapidez;
- velocidad promedio e instantánea;
- velocidad constante;
- estrategia de modelado;
- aceleración;
- diagramas de movimiento;
- aceleración constante;
- caída libre;
- integración y área bajo la curva $v-t$.
