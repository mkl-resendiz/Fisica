# Capítulo 2 — Movimiento en una dimensión

Este capítulo estudia el movimiento de una partícula a lo largo de una línea recta.

## Método de estudio

Para cada sección se incluye:

1. Resumen conceptual breve.
2. Ejemplo del libro explicado paso a paso cuando la sección contiene uno.
3. Tres ejercicios representativos tomados del conjunto de problemas del capítulo, resueltos paso a paso.
4. Un dato curioso o aplicación.
5. Fórmulas en LaTeX con interpretación física.

### Regla de ecuaciones

En las soluciones se evita saltar transformaciones importantes. Cuando corresponde, se muestra:

- ecuación original;
- despeje;
- sustitución;
- unidades;
- operaciones intermedias;
- resultado final;
- interpretación física.

> **Nota:** La numeración, terminología y ejemplos se basan en `Parte2.pdf`, capítulo 2. No se pretende reproducir el texto completo del libro.
