### Regla para ecuaciones

A partir de esta version, toda solucion numerica debe mostrar:

- ecuacion original;
- despeje algebraico;
- sustitucion de valores;
- unidades;
- operaciones intermedias importantes;
- resultado final;
- interpretacion fisica.

No se debe saltar de una formula a otra si hay una transformacion algebraica que pueda generar confusion.
