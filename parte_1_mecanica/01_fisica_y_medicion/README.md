# 01 Fisica y medicion

## Objetivo del capitulo

Este capitulo introduce las herramientas basicas que se utilizaran durante todo el curso:

- medicion y estandares;
- unidades del SI;
- modelado y representaciones;
- analisis dimensional;
- conversion de unidades;
- estimaciones y orden de magnitud;
- cifras significativas.

## Metodo de estudio

Cada apartado contiene:

1. Resumen conciso.
2. Conceptos clave.
3. Formulas importantes.
4. Ejemplo del libro explicado paso a paso.
5. Ejercicios representativos del final del apartado.
6. Dato curioso.
7. Ideas para recordar.
